# Paradise Nursery

A responsive React shopping cart application for Paradise Nursery, an online houseplant shop.

## Features
- Landing page with company story and Get Started CTA
- Nine plants across three categories
- Add-to-cart controls with disabled added state and dynamic cart count
- Cart quantity controls, remove actions, totals, checkout placeholder, and continue shopping

## Run locally
```bash
npm install
npm run dev
```
